🏆 TontineChain API Docs

Guide de Référence Intégral - Hackathon MIABE 2026

🔐 1. Authentification & OTP

POST /auth/request-otp

Demande l'envoi d'un code OTP (6 chiffres) par e-mail.

Paramètres (JSON)

  • email (string, required) : Adresse e-mail de l'utilisateur.
Response 200: { "message": "OTP envoyé...", "debug_otp": "123456" }

POST /auth/verify-otp

Vérifie le code et génère le token de session.

Paramètres (JSON)

  • email (string, required)
  • otp (string, required)
Response 200: { "token": "1|abc...", "user": { "id": 1, ... } }

👤 2. Profil Utilisateur & KYC

GET /users/me

Récupère toutes les données de l'utilisateur (incluant kyc_status).

PATCH /users/me

Met à jour les infos du profil.

  • first_name, last_name, profession, npi, preferred_language.

POST /users/me/kyc

Envoi de la pièce d'identité (Simulation OCR YAO).

Paramètres (Form-Data)

  • document (file, required) : Image de la carte d'identité.
Response: { "status": "pending", "demo_notice": "YAO analyse..." }

👥 3. Groupes & Tontines

POST /groups

Création d'une tontine.

  • name, contribution_amount, frequency (daily/weekly/monthly), max_members.

POST /groups/{id}/start

Active la tontine. Important : Cette action déploie le contrat sur la Blockchain et génère le PDF.

💰 4. Cotisations & Finances

POST /contributions/{id}/pay

Initialise un paiement FedaPay.

Response: { "url": "https://checkout.fedapay.com/...", "transaction_id": "..." }

GET /payouts

Liste des ramassages. Champ blockchain_tx_hash contient le lien vers Polygonscan.

🤖 5. IA (YAO) & Social

POST /ai/chat

Assistant intelligent multilingue.

Request: { "message": "Akwé nabi ?", "locale": "fon" }

GET /groups/{id}/messages

Chat de groupe (messages membres + alertes système).
