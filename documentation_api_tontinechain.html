🚀 TontineChain API

Documentation Complète pour le Front-End - MIABE 2026

v1.0.0 Production Ready

Base URL : https://tonnine-benin-backend.onrender.com/api/v1

Authentification : Header Authorization: Bearer <token>

🔐 1. Authentification & OTP

POST /auth/request-otp

Demande l'envoi d'un code OTP par e-mail.

Request: { "email": "user@example.com" }
Response: { "message": "OTP envoyé...", "debug_otp": "123456" }

POST /auth/verify-otp

Vérifie le code et connecte l'utilisateur.

Request: { "email": "user@example.com", "otp": "123456" }
Response: { "token": "...", "user": { ... } }

👤 2. Profil & KYC

GET /users/me

Infos complètes de l'utilisateur connecté.

POST /users/me/kyc

Upload de la pièce d'identité (Multipart/Form-Data).

Param: document (file)

GET /users/me/score

Récupère le score de confiance et les incidents.

GET /users/me/balance

Statistiques financières (Total cotisé, reçu, etc.).

👥 3. Groupes & Tontines

GET /groups

Liste de mes tontines.

POST /groups

Création d'une nouvelle tontine.

Request: { "name": "...", "contribution_amount": 10000, "frequency": "weekly", "max_members": 5 }

POST /groups/{id}/start

Démarrage officiel du cycle (Génère le contrat Blockchain et PDF).

💰 4. Paiements & Finances

GET /contributions/pending

Liste des cotisations à payer.

POST /contributions/{id}/pay

Initie un paiement FedaPay (renvoie une URL de checkout).

GET /payouts

Historique des ramassages reçus (avec liens Polygonscan).

🤖 5. IA (YAO) & Messagerie

POST /ai/chat

Assistant IA Multilingue (Français, Fon, Yoruba).

Request: { "message": "Quel est mon score ?", "locale": "fon" }

GET /groups/{id}/messages

Historique du chat de groupe (Système + Membres).

POST /groups/{id}/messages

Envoyer un message dans le chat.

⚙️ 6. Spécifications Techniques

🌍 Langues

fr, fon, yor

📅 Fréquences

daily, weekly, monthly

🏦 Ramassage

sequential (ordre fixé), bidding (enchères)
