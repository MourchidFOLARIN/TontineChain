# TontineChain - Frontend Adaptation 🇧🇯

Ce projet est la refonte du frontend de **TontineChain** pour le hackathon **MIABE 2026**.
Il a été conçu pour offrir une expérience utilisateur premium, sécurisée et conforme aux standards modernes.

## 🚀 Fonctionnalités

- **Landing Page Complète** : Hero, Problème, Solution, Infrastructure de Sécurité, Fonctionnalités, FAQ.
- **Dashboard Premium** : Vue d'ensemble des tontines, score de confiance, et navigation intuitive.
- **Infrastructure de Sécurité** : Mise en avant du NPI, Authentification OTP (SMS/WhatsApp), Score de Confiance, et Blockchain Polygon.
- **Assistant YAO** : Assistant IA intégré pour conseiller les utilisateurs sur leur épargne.
- **Messagerie Intégrée** : Communication directe et de groupe sécurisée.
- **Dark/Light Mode** : Toggle de thème dynamique préservé dans les préférences locales.
- **Responsive Design** : Adapté pour mobile, tablette et desktop.

## 🛠 Stack Technique

- **Framework** : React + Vite
- **Styling** : Vanilla CSS + Tailwind CSS (Variables dynamiques)
- **Icons** : Lucide React
- **Animations** : Framer Motion
- **API** : Intégration backend Laravel

## 📦 Installation & Déploiement

1. Installer les dépendances :
   ```bash
   npm install
   ```
2. Lancer en développement :
   ```bash
   npm run dev
   ```
3. Build pour la production :
   ```bash
   npm run build
   ```

## 🔒 Sécurité (Backend)

Le frontend met en avant les couches de sécurité du backend :
- **NPI (Vérification d'identité)**
- **OTP via Infobip (SMS/WhatsApp)**
- **Smart Contracts Polygon**
- **Paiements FedaPay**
